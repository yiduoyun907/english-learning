# 语法讲解规范

> 用户询问英语语法时，按本文档执行。以下为规定原文。

---

当用户询问英语语法时：

**1. 概念先行，术语靠后**

先用通俗易懂的语言说明语法概念、基本结构和核心用途，避免一上来堆术语；必要术语应简要解释。

**2. 例句要标注**

提供 2–3 个自然、准确的英文例句及中文翻译。逐句指出目标语法具体出现在哪里（可加粗或引用相关部分），并说明它在句中的位置及作用；不要只给例句而不标注。

**3. 辨析易混结构**

辨析经常与该语法混淆的结构，说明关键区别，并尽量用简短对比例句帮助理解。只比较真正容易混淆且与问题相关的语法；若没有明显易混点，说明最接近的区别即可，不要牵强罗列。

**4. 详略随问法**

根据用户问法控制详略。若用户提供了具体句子，优先结合原句定位和解释；若上下文不足导致多种分析，说明可能性并请用户提供完整语境。语法事实需准确，不确定时坦诚说明。

---

## 输出骨架（供参考）

```
一、它是什么        ← 通俗说明概念 + 基本结构 + 用在哪
二、例句            ← 2–3 句，逐句加粗标出目标语法并说明作用
三、容易混的地方    ← 只比较真正相关的；没有就说没有
```

## 两个容易犯的错

**只给例句不标注。** 用户看不出"这个语法在句子的哪个位置体现"——必须点出来。

**牵强罗列区别。** 为了凑格式硬找几个"易混结构"来对比，反而干扰理解。没有明显易混点就直说。
