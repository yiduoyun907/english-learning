# 作文指导规范

> 用户给出作文主题并要求写作文时，按本文档执行。以下为规定原文。

---

当用户给出作文主题并要求写作文时：

**1. 要求处理**

若用户提供了内容要求、体裁、字数、年级/英语水平等信息，先提炼并遵守这些要求；如果没有额外内容要求，就按主题采用常见、积极且符合题意的主流方向，不必为了缺少细节而追问。若字数或水平完全未说明，选择适合普通英语学习者的自然表达与适中篇幅，并可简短注明假设。

**2. 写作思路与常用表达**

先梳理写作思路和文章结构（如开头、主体、结尾及要点安排），再给出与主题相关、地道且可实际运用的常用高分短语和句子，并附中文释义或用途提示。避免生硬堆砌复杂词汇；"高分"表达应准确、自然并适合用户水平，不承诺分数。

**3. 完整作文**

随后生成 2–3 篇完整作文。每篇都应切合题目、结构完整、语法和用词准确；若用户明确要求只写一篇或限定篇数，以用户要求为准。若篇幅较长，可先提供精炼版本，或说明篇幅设定。

**4. 讲解与迁移**

作文之后说明文章亮点（如结构、表达、论证/细节），并总结可复用的句子结构或模板，标明可替换的部分，帮助用户迁移到其他主题。避免模板化重复；若多篇文章采用不同角度，可指出差异。

**5. 组织顺序**

可按"要求分析—写作思路—常用表达—完整作文—亮点—可复用句型"组织。若题目本身明显有歧义或必要要求冲突，再简短澄清；否则直接完成。

---

## 输出骨架（供参考）

```
一、要求分析        ← 提炼用户给的要求；没给就说明采用的假设
二、写作思路        ← 开头 / 主体 / 结尾各写什么，要点怎么排
三、常用表达        ← 短语与句子 + 中文释义或用途提示
四、完整作文        ← 2–3 篇，角度可不同
五、亮点            ← 每篇好在哪里
六、可复用句型      ← 标明可替换部分
```
