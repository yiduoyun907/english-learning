# 单词讲解规范

> 用户询问某个英语单词的含义时，按本文档执行。以下为规定原文。

---

当用户询问某个英语单词的含义时，按以下顺序回答：

**1. 开门见山给释义**

开门见山列出该词最常用的中文释义；若有词性差异，标明词性。优先讲常用义，不要一开始铺陈。若同一拼写有多个常见义，按常用程度挑选，并清楚区分词性、含义和用法；没有上下文时说明具体含义可能随语境变化。

**2. 词源与记忆**

简要说明词源、构词方式或词根/词缀如何帮助理解和记忆。确保词源信息可靠；若历史来源不确定或不适合拆解，明确说明，不要把牵强联想说成真实词源。可以另给一个明确标注为"记忆小窍门"的助记法。

**3. 例句**

给出 3–5 个高频、自然的英文例句及对应中文翻译，尽可能覆盖该词的不同常见释义或用法；每条例句标明对应释义/用法。例句简短、实用，翻译准确。若该词常见释义很多，优先覆盖最常用的几种，不必穷举。

格式可按"常用释义—词源/词根—例句—记忆小窍门（可选）"组织。根据用户问题调整详略；如果用户只问一个特定语境，也先简要给常用义，再重点解释该语境。对于拼写、词性或上下文有歧义时，先说明可能情况，必要时请用户提供完整句子。不要为了套用固定格式而给用户不需要的冗长内容。

---

## 输出骨架（供参考）

```
一、常用释义    ← 先给最常用的；有词性差异就标明
二、词源 / 词根  ← 可靠才写；不确定就明说
三、例句        ← 3–5 句，每句注明对应哪个释义
四、记忆小窍门  ← 可选，且明确标注这是助记法而非真实词源
```

## 三条红线

**不要把牵强联想说成真实词源。** 词源要可靠；历史上说不清就直说"这个词的来源不太确定"。助记法可以用，但必须**明确标注为"记忆小窍门"**，不能混进词源里。

**不要一上来铺陈。** 用户问"xx 什么意思"，第一句话就该是最常用的释义，不是背景知识。

**不要为了套格式而啰嗦。** 用户只问某个语境下的意思，就给常用义 + 重点解释那个语境，不必把整个模板填满。
